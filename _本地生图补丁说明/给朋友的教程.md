# st-chatu8 本地生图 · 安装与使用教程（整合版：LocalDream + FancyAI）

这个补丁给 **st-chatu8（智绘姬）v3.1.5** 增加了完整的「本地生图」支持：
- 支持 **LocalDream**（端口 `8081`）
- 支持 **FancyAI Aura LAN**（端口 `7861`）

开启后生图不再请求远程 sdwebui，而是直接调用手机端侧的本地生图模型出图。

---

## 模式说明与对比

| 引擎类型 | 默认地址 | 手机端配套软件 | 特点 |
| :--- | :--- | :--- | :--- |
| **FancyAI (推荐)** | `http://127.0.0.1:7861` | FancyAI App (打开 Aura LAN 共享) | 走手机原生 NPU/GPU 极速出图，模型和工作流直接在 FancyAI 内选定 |
| **LocalDream** | `http://127.0.0.1:8081` | LocalDream 本地服务 | 支持从酒馆侧传递步数、CFG、采样器与尺寸参数 |

---

## 快速配置使用

### 场景 A：使用 FancyAI 本地生图（7861 端口）

1. **手机端准备**：
   - 打开 **FancyAI** App；
   - 进「Aura (绘图)」页面，预先选好你要用的生图模型，并调整好你满意的分辨率与步数；
   - 开启 **「Aura LAN 共享」**（或允许局域网访问），App 会在后台监听 `7861` 端口。
2. **酒馆端配置**：
   - 打开 SillyTavern，进 **文生图设置 → Stable Diffusion**；
   - 勾选 **「启用本地生图」**；
   - 本地引擎选择：**`FancyAI Aura LAN (默认端口 7861)`**；
   - 上方的「API 地址」填入：`http://127.0.0.1:7861`；
   - 点击 **「连接刷新数据」** → 提示连接成功！
3. **聊天出图**：
   - 顶部「模式」选择 **Stable Diffusion**；
   - 回聊天窗口，直接用 `image###1girl, white hair, smile###` 触发出图。

---

### 场景 B：使用 LocalDream 本地生图（8081 端口）

1. 手机打开 LocalDream 服务（监听在 `8081`）。
2. 在智绘姬「本地生图」区域勾选启用，引擎选 **`LocalDream`**。
3. API 地址填：`http://127.0.0.1:8081`。
4. 点「连接刷新数据」测试在线后即可使用。
